阶段三 · 分割

阈值分割

把灰度图变成前景/背景是最实用的分割手段，但“阈值取多少”本身是一个优化问题。本文推导 Otsu 的类间方差目标，说明二值化的比较约定，并解释为什么光照不均时全局阈值必然失效。

01 · 一个数字能决定什么

二值化的规则简单到一句话：灰度大于某个阈值就判为前景，否则判为背景。困难完全在于选阈值。手挑一个数（比如 120）在示例图上也许还行，但换一张整体偏亮的图就全乱。Otsu 方法给出一个不依赖手工调参的答案：挑那个能让“前景/背景两类的类内差异最小”的阈值——等价于让两类类间方差最大。

它成立的前提是：灰度直方图呈现双峰，且两峰之间的谷底对应阈值。当光照不均或前景占比极小，这个前提就被破坏，于是需要自适应阈值用局部邻域来替代全局统计。

02 · 核心机制：最大化类间方差

把归一化直方图记为 p_i（灰度 i 的出现频率，Σp_i = 1）。对候选阈值 t：

  • 左侧（背景）的累计概率 ω(t) = Σ_{i≤t} p_i，一阶矩 μ(t) = Σ_{i≤t} i·p_i。
  • 右侧（前景）的概率是 1 − ω(t)，其均值由全图均值 μ_T 与 ω(t), μ(t) 推出。

类间方差可以写成只依赖累计量的闭式，无需为每个阈值重算均值：

σB2(t)= (μT·ω(t)−μ(t))2 ω(t)·(1−ω(t))

把这个式子对 t = 0…255 求值，取最大处（并列时取第一个，与常见离散实现一致）：

t*= arg max0≤t≤255 σB2(t)

分母 ω(t)·(1−ω(t)) 在 ω(t)=0 或 1（阈值落在直方图两端之外）时为 0。参考实现显式地把这些位置排除，避免除零产生 NaN——这是工程实现的必要处理，论文级公式默认概率非退化。

03 · 从阈值到二值图

选定阈值后，二值化是一个逐像素的硬判决。本仓库的约定是严格大于：

def binary_threshold(image, threshold):
    return np.where(image > threshold, 255, 0).astype(np.uint8)

注意边界：像素恰好等于阈值时归为背景（0），而不是前景。这个约定必须与对照实现一致，否则会出现整行像素的差异。共享管线里 otsu 分支用同一个 binary_threshold 生成结果，并把它与 cv2.threshold(..., THRESH_BINARY + THRESH_OTSU) 逐像素比较，把不一致的像素数记为 reference_pixel_difference。这个指标是“参考一致性”的证据，不是“分割质量”的证据——两套实现完全一致，也可能都分割得很差。

04 · 自适应阈值：把阈值变成局部量

全局阈值的致命假设是“整张图光照均匀”。一旦有光照梯度，同一个灰度值在亮区可能属于背景、在暗区可能属于前景，任何单一阈值都会在某一侧失败。

自适应阈值的做法：对每个像素，用它的局部邻域（共享管线用高斯加权邻域）估计一个局部基准，再减去一个常数偏置 C，得到该像素专属的阈值。于是阈值本身随位置变化，能够跟随光照漂移。

06 · 边界与取舍

失败模式

一是单峰直方图：没有真正的两类，Otsu 仍会返回一个阈值并把图像切成两半，但切法没有语义。二是光照不均：全局统计被照度梯度主导，需换自适应阈值。三是噪声：二值化前若不做滤波，孤立噪点会变成孤立的前景斑块——这正好是下一阶段（形态学）要清理的对象。

自适应阈值的注意点

邻域尺寸 kernel 必须为奇数且足够大于目标尺寸，否则会“只在目标内部产生局部对比”，把大块前景掏空。共享管线把邻域尺寸直接绑定到滑块的 kernel 参数，取值范围 3…31，因此无法通过界面传入选址所需的更大窗口。偏置 C 在管线里固定为 3，属于简化选择。
