# W06 — Morphological processing

**Level:** Beginner  
**Status:** implemented

## Learning objectives

Erosion, dilation, opening, closing, components

## Engineering deliverable

Remove noise and count connected regions

## Lab protocol

1. Derive or explain the mathematical objective and algorithm assumptions.
2. Build a deterministic synthetic test case; record the input dimensions and datatype.
3. Implement a reference in NumPy where feasible and compare to OpenCV.
4. Sweep important parameters, visualize intermediate outputs and identify failure modes.
5. Write at least one correctness test and report measured runtime for fixed inputs.

## Completion gate

A runnable example, result images, documented negative case, test output and benchmark record must be attached before this lesson is considered complete.

## v0.2 guided experiment — mathematical morphology

Erosion is a local minimum and dilation a local maximum for a flat structuring element. Opening = erosion followed by dilation; closing = dilation then erosion. Use `morphology_manual` for a **rectangular** element and compare against `cv2.MORPH_RECT` across random inputs and boundary pixels.

The interactive app uses an *elliptical* structure element for its final result, so its output must not be evaluated against the rectangular reference as if both had identical assumptions. Test small isolated islands, single-pixel holes, and objects touching the image border.

**Gate**: provide two binary test images demonstrating a case where opening destroys useful structure and a case where closing merges two nearby objects. Explain the tradeoff.
