# W03 — Convolution and denoising

**Level:** Beginner  
**Status:** implemented

## Learning objectives

Correlation, Gaussian, median, bilateral filtering

## Engineering deliverable

Reproduce Gaussian filtering from first principles

## Lab protocol

1. Derive or explain the mathematical objective and algorithm assumptions.
2. Build a deterministic synthetic test case; record the input dimensions and datatype.
3. Implement a reference in NumPy where feasible and compare to OpenCV.
4. Sweep important parameters, visualize intermediate outputs and identify failure modes.
5. Write at least one correctness test and report measured runtime for fixed inputs.

## Completion gate

A runnable example, result images, documented negative case, test output and benchmark record must be attached before this lesson is considered complete.

## v0.2 guided experiment — Gaussian vs median

The two-dimensional Gaussian kernel is separable: \(G(x,y;\sigma)=g(x;\sigma)g(y;\sigma)\). Verify that kernel weights sum to one, that kernel size and sigma affect effective smoothing, and why border rules matter. Implement `gaussian_manual` and `median_manual` in NumPy; verify `medianBlur` parity on 1x1, 2x3 and random images.

Generate Gaussian and salt/pepper noise with a **fixed seed**. Use `opencv-lab ablate` with `--algorithm gaussian --study sigma` and repeat for `--algorithm median --study kernel`. Report input/ground-truth dimensions, seed, noise strength, before/after MAE, PSNR and SSIM. Explain why increasing blur does not always increase SSIM. Keep runtime comparisons outside single-shot ablation.

**Failure case**: thin lines and small text can disappear when large kernels remove fine detail. A high PSNR by itself does not guarantee semantic readability.

**Gate**: `pytest -q tests/test_v02_references.py tests/test_v02_experiments.py` plus one JSON report and one PNG contact sheet with interpretation.
