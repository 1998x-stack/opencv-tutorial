# W22: CPU/GPU performance methodology

**Track:** Advanced — v0.4 first lab iteration. The final external-dataset capstone is not completed by this document.

## Theory and derivation

Understand performance confounders: decode, model init, preprocess, forward, NMS, sync.

## Hands-on implementation

Run bench-dnn on toy local model with warmups and 10+ repetitions, report median/p95.

## Evidence-based acceptance

Never infer GPU performance from CPU-only environment or forward-only timings.

Use `python -m pytest -q` and `python -m opencv_tutorial evaluate-advanced --seed 17`. Record OpenCV version, seed, image size, units and limitations. For a real camera, calibrate and rectify before interpreting geometry as meters.
