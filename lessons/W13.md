# W13 — Background motion

**Theme:** Frame differencing, MOG2, background adaptation and false positives.

## Concept

Study the objective, assumptions and failure modes of this week's method.

## Lab

1. Run the v0.3 intermediate observatory (`python -m opencv_tutorial serve`).
2. Execute the reference CLI (`panorama`, `flow`, or `track` as applicable).
3. Inspect actual feature matches, inliers, optical flow and track IDs.
4. Design one counter-example (blank texture, poor overlap, lighting change, crossing paths).

## Assessment

- Record all fixed parameters, versions, image resolution and transform labels.
- Write at least two successful assertions and one expected failure assertion.
- Do not claim general-scene accuracy from only the supplied synthetic fixtures.

See [`docs/v0.3-intermediate.md`](../docs/v0.3-intermediate.md).
