# W04 — Gradients and edges

**Level:** Beginner  
**Status:** implemented

## Learning objectives

Sobel, Scharr, Laplacian, Canny

## Engineering deliverable

Visualize horizontal and vertical gradients

## Lab protocol

1. Derive or explain the mathematical objective and algorithm assumptions.
2. Build a deterministic synthetic test case; record the input dimensions and datatype.
3. Implement a reference in NumPy where feasible and compare to OpenCV.
4. Sweep important parameters, visualize intermediate outputs and identify failure modes.
5. Write at least one correctness test and report measured runtime for fixed inputs.

## Completion gate

A runnable example, result images, documented negative case, test output and benchmark record must be attached before this lesson is considered complete.

## v0.2 guided experiment — inspect actual gradients

For intensity \(I(x,y)\), compute finite-difference partial derivatives \(I_x, I_y\), gradient magnitude \(\sqrt{I_x^2+I_y^2}\), and direction \(\mathrm{atan2}(I_y,I_x)\). Preserve signed float arrays for numeric checks; rendered 8-bit images lose sign and scale. Compare `sobel_manual` with `cv2.Sobel` pixel-wise.

Explore Canny with fixed Gaussian smoothing and varied thresholds. Browser playback shows real grayscale, smoothed image, gradient magnitude and final edge map. Non-maximum suppression and hysteresis are implemented internally by OpenCV; do **not** claim to visualize either step independently.

**Failure case**: very weak edges merge into noise at low thresholds; high thresholds miss structure. Without labeled edge maps no PSNR/SSIM quality score is valid for grayscale-versus-edge comparisons.
