# v0.3 — Intermediate Vision Observatory

**Scope:** W09–W16 feature geometry, panorama stitching, sparse optical flow, tracking; supports local CLI and two-image HTTP experiments.

## Algorithms and assumption boundaries

| Algorithm | Implementation | Input and assumptions | Controlled validation |
|---|---|---|---|
| ORB + RANSAC + homography | `opencv_tutorial.panorama.stitch_pair` | Two overlapping `uint8` BGR images; planar or near pure rotation | Known 230-pixel crop offset, 90+ inliers, accepted canvas bounds |
| Pyramidal LK | `opencv_tutorial.optical_flow.sparse_lk` | Consecutive grayscale/BGR frames with same dimensions and sufficiently small motion | Known `(dx=7,dy=4)` global shift, EPE, forward/backward gating |
| Centroid association | `opencv_tutorial.tracking.CentroidTracker` | External axis-aligned `(x,y,w,h)` detections; sufficiently slow movements | Two independent IDs, one-to-one assignment, disappearance TTL |
| MOG2 → tracker | `opencv_tutorial.cli` `track` | Fixed camera and detectable foreground | Video output smoke test; no arbitrary identity correctness guarantee |

### Failure modes and why they matter

- Panorama: a homography is invalid for appreciable parallax / independent moving objects. Poor image overlap and weak texture must be rejected, not silently produce black or distorted mosaics. `min_inliers`, inlier ratio, projected area and output canvas area are gated.
- LK: brightness-constancy assumption can fail under illumination change; forward/backward error gating rejects unstable tracks. No features means empty result, **not** perfect tracking.
- Centroid tracker: crossing tracks, long occlusions, camera shake, detection failures or rapid motion can break identity consistency. Track IDs are not ground-truth identity labels.
- Synthetic benchmark: demonstrates recoverable geometry and numerical self-consistency. It does **not** measure natural-scene quality or MOT challenge performance. Do not compare this to KITTI/MOT benchmark scores.

## Reproduce locally

```bash
pip install -e '.[dev]'
pytest -q
python -m opencv_tutorial evaluate-intermediate --seed 17 --output results/intermediate.json
python -m opencv_tutorial serve
# Browser http://127.0.0.1:8765/#intermediate
```

```bash
python -m opencv_tutorial panorama --first images/left.png --second images/right.png --output results/panorama.png
python -m opencv_tutorial flow --first images/frame01.png --second images/frame02.png --output results/flow.png
python -m opencv_tutorial track --input videos/camera.mp4 --output results/tracked.mp4
```

Pair experiments are stateless: `/api/intermediate/panorama`, `/api/intermediate/flow`. Synthetic fixtures: `GET /api/intermediate/sample`, `GET /api/intermediate/tracking-demo`.

## Acceptance gates

1. All v0.2 tests still pass.
2. Synthetic known transformations are recovered within numerical tolerance.
3. Blank/degenerate inputs fail deterministically with 400 and a useful reason.
4. Track lifecycle and matching uniqueness are covered by unit tests.
5. CLI smoke, API integration and headless UI exercise all operate on actual algorithm output.
